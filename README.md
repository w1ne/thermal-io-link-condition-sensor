# Thermal IO-Link Condition Sensor

[![verify](https://github.com/w1ne/thermal-io-link-condition-sensor/actions/workflows/verify.yml/badge.svg)](https://github.com/w1ne/thermal-io-link-condition-sensor/actions/workflows/verify.yml)

An MLX90640 thermal camera and an ESP32-C3 classify a machine's thermal fingerprint on-edge and report a STABLE/WARN/FAULT verdict over IO-Link. The firmware is booted on the open LabWired engine and the page is verified only if the run passes its acceptance checks; Export to GitHub turns it into a self-verifying repo.
